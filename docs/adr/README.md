# Architecture decision records

Significant, hard-to-reverse decisions are recorded here, one file per decision, named `NNNN-short-title.md` (e.g. `0001-star-topology-only.md`). Each record states the context, the decision, and the consequences; the conventions agents follow when reading or writing them are in [`docs/agents/domain.md`](../agents/domain.md).
